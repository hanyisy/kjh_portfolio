# 관리자 페이지 설정

관리자에서 「저장」을 누르면 **Vercel 서버 함수**가 대신 깃허브에 커밋하고,
GitHub Pages 가 그걸 받아 사이트를 갱신합니다.

```
관리자 화면 ──(비밀번호)──▶ Vercel 함수 ──(토큰)──▶ 깃허브 저장소
                                                      │
                                      GitHub Pages ◀──┘  약 1~2분 뒤 반영
```

깃허브 토큰과 비밀번호는 **Vercel 환경변수에만** 있습니다. 브라우저로 내려가지
않고 저장소에도 들어가지 않습니다.

- **공개 사이트 주소는 그대로입니다** — `hanyisy.github.io/kjh_portfolio/`
- **관리자만 Vercel 주소로** 들어갑니다. GitHub Pages 쪽 관리자 주소로 열면
  저장 기능이 없어 「보기 전용」으로 뜹니다.

---

## 1. 깃허브 토큰 만들기

1. 깃허브 → 오른쪽 위 프로필 → **Settings**
2. 맨 아래 **Developer settings** → **Personal access tokens** → **Fine-grained tokens**
3. **Generate new token**
   - **Token name** `kjh-portfolio-admin`
   - **Expiration** 원하는 기간 (만료되면 새로 만들어 Vercel 에 다시 넣으면 됩니다)
   - **Repository access** → **Only select repositories** → `kjh_portfolio` **하나만**
   - **Permissions** → Repository permissions → **Contents** 를 **Read and write** 로
     (나머지는 전부 건드리지 마세요)
4. **Generate token** 누르고 나오는 `github_pat_…` 를 복사합니다.
   **이 화면을 닫으면 다시 볼 수 없습니다.**

> 저장소 하나에만, Contents 권한만 준 토큰입니다. 혹시 새더라도 다른 저장소나
> 계정 설정에는 손댈 수 없습니다.

## 2. Vercel 에 올리기

1. [vercel.com](https://vercel.com) 에 깃허브 계정으로 로그인
2. **Add New → Project** → `kjh_portfolio` 선택 → **Import**
3. 설정은 건드릴 것이 없습니다. Framework Preset 은 **Other**, 나머지는 비워 둡니다.
4. **Deploy**

## 3. 환경변수 넣기

Vercel 프로젝트 → **Settings** → **Environment Variables** 에서 네 개를 넣습니다.
(Environment 는 **Production** 체크)

| 이름 | 값 |
|---|---|
| `ADMIN_PASSWORD` | 관리자 페이지에서 쓸 비밀번호 (직접 정하세요) |
| `GITHUB_TOKEN` | 1번에서 복사한 `github_pat_…` |
| `GITHUB_REPO` | `hanyisy/kjh_portfolio` |
| `GITHUB_BRANCH` | `main` |

넣고 나서 **Deployments → 맨 위 … → Redeploy** 를 한 번 눌러야 적용됩니다.
(환경변수는 새로 배포할 때 읽힙니다.)

## 4. 들어가기

```
https://<프로젝트이름>.vercel.app/admin-a358de594b6f.html
```

비밀번호를 넣으면 들어갑니다. 비밀번호는 **탭을 닫을 때까지만** 기억합니다.

---

## 알아 둘 것

**저장 후 1~2분** — 커밋은 바로 되지만 GitHub Pages 가 사이트를 다시 만드는 데
시간이 걸립니다. 바로 안 보여도 잠시 기다리세요.

**올릴 수 있는 파일은 3MB 까지** — 서버 함수가 한 번에 받는 양에 한계가 있습니다.
그보다 큰 이미지나 **영상**은 깃허브 웹에서 직접 올리고, 관리자에서는 파일 이름만
적어 주세요. 「폴더 확인」 단추를 누르면 직접 올린 파일을 찾아 줍니다.

**쓸 수 있는 곳은 두 군데뿐** — 서버 함수는 `data/site.json` 과 `assets/` 아래에만
씁니다. 비밀번호가 새더라도 `index.html` 이나 `.github/` 같은 곳은 건드릴 수 없습니다.

**되돌리기** — 모든 수정이 깃허브 커밋으로 남습니다. 잘못 고쳤으면 저장소의
커밋 기록에서 되돌리면 됩니다.

**비밀번호를 바꾸려면** Vercel 환경변수의 `ADMIN_PASSWORD` 를 고치고 Redeploy 하세요.
